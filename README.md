# 📊 Dashboard de Análise de Dados

Aplicação desktop desenvolvida em **C#** com **Windows Forms**, focada na visualização e análise de dados de vendas através de dashboards interativos.

O projeto apresenta indicadores, gráficos e métricas para auxiliar na análise do desempenho comercial, demonstrando conceitos de desenvolvimento desktop utilizando a plataforma .NET.

---

## 🚀 Funcionalidades

- 📈 Dashboard com indicadores de vendas
- 💰 Total de faturamento
- 📦 Quantidade de pedidos
- 🌎 Análise por região
- 📅 Análise por período
- 📊 Visualização de métricas em tempo real
- 🖥️ Interface desenvolvida com Windows Forms

---
